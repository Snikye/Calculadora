# Calculadora Científica

Calculadora científica visual construida con Node.js 18.

## Características

- Operaciones básicas: suma, resta, multiplicación, división
- Funciones científicas: sin, cos, tan, log, ln, √, ∛, x², x³, xʸ, |x|, 1/x
- Constantes: π, e
- Soporte de paréntesis y porcentaje
- Teclado compatible
- Interfaz visual moderna

## Requisitos

- Node.js >= 18

## Instalación y uso

```bash
npm start
```

La aplicación estará disponible en `http://localhost:3000`.
